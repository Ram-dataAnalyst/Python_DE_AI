# Python_DE_AI
Build an AI-Powered Data Profiler &amp; Data Governance/Modeling/Quality Analyser
Automated Ingestion Lifecycle: Source files land in landing/ and are safely transitioned through processing → archive/error.
Pandas Profiling Engine: Inspects and profiles every dataset to capture structural schemas, Pandas dtypes, null percentages, and column metrics.
AI Governance & PII Tagging: Leverages AI for semantic domain classification, sensitive PII identification, and compliance tagging.
Data Quality & Schemas: Generates automated data quality validation rules and target SQL/DDL schema models saved to data/output/.
